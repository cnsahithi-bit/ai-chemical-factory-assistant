Assumptions and limitations

  • Images and production runs are paired by index for the demo; no dataset links a specific image to a specific run.
  • Zone attribution is rule/score based (defect prior x production stress). It ranks likely zones; it does not prove a cause.
  • Localization is a weakly supervised heatmap (no ground-truth boxes were provided), so its precision cannot be measured.
  • Economic parameters (price, cost, rework, holding cost) and the base defect rate are assumptions, to be replaced by organizer data.
  • Calibration uses temperature scaling with T>=1 (never sharpens confidence). The test set is class-balanced, so its accuracy is not a production defect-rate estimate.
  • Robustness tests are synthetic perturbations; they approximate, not replace, real changes in lighting and part orientation.
